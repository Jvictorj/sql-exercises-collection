# 🐘 **SQL Exercises & Solutions**

Repositório contendo aulas, desafios e resoluções em SQL, baseados em estudos pessoais, materiais acadêmicos e exercícios de plataformas como HackerRank, LeetCode e SQLZoo.

Este repositório serve como documentação e prática contínua de consultas SQL, conceitos de banco de dados e resolução de problemas reais.

## 🧠 **Sobre o Projeto**

Este repositório reúne:

* PDFs das aulas
* Exercícios e desafios de SQL
* Minhas soluções
* Consultas otimizadas
* Anotações importantes
* Bancos de dados usados nos exercícios

O objetivo é ter um espaço organizado para estudo contínuo de SQL.

---

## 🚀 **Como Usar**

1. Baixe ou visualize os PDFs em `/pdfs`
2. Leia o exercício
3. Confira a solução em `/solutions`
4. Carregue os datasets em `/datasets` (se houver)
5. Execute no PostgreSQL / MySQL / SQLite ou outro SGBD

---

## 🗂️ **Estrutura do Repositório**

```
pdfs/          → PDFs com aulas e desafios  
solutions/     → Arquivos .sql com minhas resoluções  
datasets/      → Arquivos CSV ou SQL usados nos exercícios

```
